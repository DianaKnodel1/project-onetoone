# Ausführliche Anleitung („Deckblatt") für den Landing-Generator — direkt im Chat

## Ziel
Eine vollständige, verständliche Anleitung zum klassischen Landing-Generator, die direkt hier im Chat erscheint und zum Weiterschicken an den Kollegen gedacht ist. Kein Code, keine App-Änderung — nur ein Dokument als Chat-Nachricht.

## Inhalt der Anleitung
1. **Was ist der Landing-Generator** — Zweck: fertige Bewerbungs-Landingpages (eigene Domain, Hosting auf Server 1, SSL automatisch) für Bewerbung → Calendly-Termin → Registrierung im Mitarbeiterportal.
2. **Übersicht der Seite** — Kopfzeile, Liste der gespeicherten Landings (Domain, Slug, Theme, Status live/pausiert, Setup-Prüfung, Bearbeiten/Duplizieren-als-Vorlage/Aktivieren/Löschen), Buttons „Neue Landing", „Zum Baukasten", „Vorschau ein/aus".
3. **Schritt 1 — Theme wählen** — alle Vorlagen sind „direkt" (kein Fast-Track/Vermittlung-Unterschied mehr für neue Seiten); Auswahl über Karten; „Eigene Vorlage" (aus dem Baukasten gespeicherte Vorlagen) lädt direkt in den Generator; „Gespeicherte Baukasten-Seiten verwenden" erzeugt eine Kopie.
4. **Schritt 2 — Branding & Inhalte** — Setup-Vorlage mit Pflichtfeldern (Firmenname, Kontakt-E-Mail, Landing-Domain, API-Endpoint, Tenant-ID, Portal-URL), optionale Felder (Logo, Favicon, Farben, WhatsApp, Adresse, Impressum-Daten, HRB/USt-IdNr., Telefon 2), Tracking-Slug, Meta-Pixel-ID + eigener Pixel-Code, KI-Bewerbungsgespräch (Chat/Telefon/Beides, Stimme, Profilbild, eigener System-Prompt), Terminbuchung über Calendly.
5. **Schritt 2b — Theme-Inhalte** — jedes Theme bringt eigene Text-/Bildfelder (Slots) mit.
6. **Schritt 2c — SEO & Browser-Tab** — Seitentitel, Meta-Beschreibung, OG-Bild.
7. **Schritt 3 — Speichern & live schalten** — interner Slug, Speichern, ZIP-Export als Backup, Impressums-Prüfung, DNS-Anleitung (A-Record auf Server 1, Cloudflare-Hinweis).
8. **Live-Vorschau rechts** — reagiert sofort, „In neuem Tab öffnen".
9. **Ablauf für eine neue Seite von null bis live** — Schritt-für-Schritt-Checkliste.
10. **Häufige Fehler & Tipps** — z. B. fehlende Tenant-ID (Bewerbung landet beim falschen Kunden), fehlender Firmenname (KI stellt sich unpersönlich vor), Impressums-Pflichtfelder, Domain-Verhalten, Löschen (Termine bleiben erhalten).

## Vorgehen
- Anleitung als gut gegliederte Markdown-Nachricht im Chat senden (Titel „Deckblatt / Anleitung Landing-Generator", 8–12 Abschnitte, kompakt aber vollständig).
- Keine Datei nötig, außer der Kollege soll sie als Dokument bekommen — dann zusätzlich als PDF in Files (auf Nachfrage).
